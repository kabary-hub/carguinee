# ADR-003 : Internationalisation (i18n)

**Statut** : Accepté  
**Date** : 2025  
**Décideurs** : Équipe CarGuinée

## Contexte

CarGuinée cible le marché guinéen (français) mais doit être accessible en anglais pour les investisseurs et partenaires internationaux.

## Décision

- **Librairie** : react-i18next (standard React, lazy loading des namespaces)
- **Langues** : Français (défaut) + Anglais
- **Détection** : browser language → localStorage → fallback FR
- **Stockage** : clés dans `public/locales/{fr,en}/translation.json`
- **Toggle** : bouton FR/EN dans le header (persisté dans localStorage)

## Alternatives considérées

- **FormatJS** : Plus lourd, moins d'adoption React
- **Lingui.js** : Compilation nécessaire, overkill pour 2 langues

## Conséquences

- ✅ Les deux langues sont complètes
- ✅ Ajout de nouvelles langues = traduire 1 fichier JSON
- ⚠️ Certaines chaînes hardcodées en français restent (à corriger progressivement)
